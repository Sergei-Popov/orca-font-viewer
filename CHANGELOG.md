# Changelog

All notable changes to this plugin are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow
[Semantic Versioning](https://semver.org/). `scripts/release-plugin.sh` in the hub turns
`[Unreleased]` into the released version.

## [Unreleased]

### Changed

- WOFF 2.0: the Brotli dictionary ships as a readable word list (`vendor/brotli/dictionary.mjs`,
  generated by `tools/make-brotli-dictionary.mjs` from google/brotli's `dictionary.bin`; a test
  checks it against the RFC 7932 sha256) instead of a base64 copy inside brotli.js, and loads only
  when the first WOFF 2.0 file opens. Fonts decode byte for byte as before.
- The fonts the unit tests read are written in code, table by table (`src/font/test-fonts.ts`), in
  place of base64 copies; the repository holds no font data.
- Listing images and description: a new cover and five screenshots in the hub's house style
  (variable axes, OpenType features, characters by Unicode block, a font collection's faces, the
  Info tab), built by `scripts/listing-image.sh` from `tools/listing.json` with OFL demo fonts
  that `tools/listing-samples.sh` downloads at pinned sha256s and never commits. The manifest
  lists each image with its alt text only, and the description is shorter (298 characters).
- Characters search: words are a block search only when they begin words of the name of a block
  the font has (by its English name or its name in the UI language), so "ate" no longer finds
  "Private Use Area"; otherwise the box searches for the characters typed, however many, so
  "greek" in a font without Greek finds g, r, e and k. A single word of up to eight characters that
  only begins a block name, and whose characters are all in the font, shows both: "сим" shows с, и,
  м first, then the symbol blocks.

### Fixed

- Hostile fonts can no longer stall the tab or exhaust memory:
  - The character map reader pays every step (code points, segments, groups, glyph reads past the
    table) from one budget per character map, shared by all its subtables, and tries at most 16
    subtables.
  - A collection's face picker labels share one budget and fall back to `#n`; faces that point at
    one `name` table with different lengths parse it once; WOFF 2.0 collections, like sfnt ones,
    may list at most 10,000 faces.
  - Names used as labels (instances, axes, features, the header) are cut at 256 characters, at most
    1,000 named instances are read, and one `name` table decodes at most 4 MiB of text.
  - A collection face whose tables overlap or add up to more than the file is not cut out; the
    "could not load this font" notice says why. When Chromium refuses a font, the viewer no longer
    retries the same bytes as a `data:` URL.
- The block filter's "No block" option showed every character; all the gaps between blocks now
  share one option that shows only them.
- Monospaced fonts whose `post` table does not say so (Noto Sans Mono, Roboto Mono, Monaco,
  Courier) get the Monospaced badge, by OS/2 PANOSE or by their widths: at least 90 of the 94
  printable ASCII characters, each on a glyph of its own, nearly all one width, and that width also
  the width of at least 80% of the glyphs the font maps. Emoji fonts (only `#*0-9` in ASCII),
  fallback fonts (one glyph for everything) and dual-width CJK fonts are not counted.
- Russian UI: weight and width classes have Russian names, the symbol font note and the reason a
  face cannot be shown are translated, petite capitals are "мини-капитель", the line height and the
  axis ranges in the slider tooltips use a decimal comma, and the block filter's counts group their
  digits as the rest of the UI does.
- README and code comments gave Orca's limit for plugin editors as 64 MiB; it is 50 MiB. The README
  has a Known limits section, and `vendor/README.md` links each library's upstream.

## [0.1.0] - 2026-11-14

### Added

- **Font Viewer** custom editor for `.ttf`, `.otf`, `.woff`, `.woff2`, `.ttc` and `.otc`: the
  default view for these files, read-only and offline.
- Preview tab: editable sample text (a Russian pangram for a Russian UI when the font has
  Cyrillic, else the font's own sample or an English pangram), size from 8 to 200 px with
  presets, line height, a waterfall of nine sizes and the alphabet lines the font covers.
- Variable fonts: a slider per axis that reaches the axis's exact minimum, maximum and default,
  and the named instances; only the axes you move or an instance sets are applied, so the browser
  keeps its automatic optical size. OpenType feature switches with readable names (stylistic sets
  use the names the font gives them).
- Collections: a face picker; only the chosen face is read in full and drawn on its own, and a
  face that cannot be read is marked in the picker while the others still open.
- Characters tab: every mapped character grouped by Unicode block, drawn only where it is on
  screen, a search by character, `U+0416`, a `U+0400-04FF` range or the words of a block name
  (`latin-1`, `box draw`, `IPA ext`), a block filter, arrow-key navigation that keeps its column
  across blocks, and a detail panel with the character large on its baseline and its code
  point as U+, decimal, HTML, CSS, JavaScript and UTF-8, each with a copy button.
- Info tab: names (links open in the browser through Orca), weight, width, metrics, licence,
  embedding rights, format, outlines, file size, glyph and character counts, dates, colour
  formats, problems found while reading (tables cut off by the end of the file, a damaged
  character map skipped for the next one), and the table directory. A font whose `head`, `name`
  or `cmap` is missing or cut off gets a "damaged" message instead of an empty view.
- Font parser for sfnt, collections, WOFF 1.0 (fflate) and WOFF 2.0 (brotli.js), unit-tested on
  fonts built by `tools/make-fixtures.py` and on damaged and hostile fonts built in the tests.
  WOFF and WOFF 2.0 data never unpacks past the sizes the file's directory gives (256 MiB at
  most; both decoders are patched to stop there), overlapping character map ranges and oversized
  `fvar` and `name` tables are bounded, Mac Roman character maps are decoded in every format, and
  a face cut out of a collection gets valid checksums.
- English and Russian UI, Orca's light and dark themes, "Aa" icons.
